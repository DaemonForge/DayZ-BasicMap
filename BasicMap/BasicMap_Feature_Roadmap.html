🛠️ Stability & Polish Q1 2025
  • 🔧

    Bug Fixes

    Complete missing pen requirement check, fix potential null reference errors in HUD updates

  • 🌍

    Multi-Map Support

    Dynamic map bounds detection instead of hardcoded Chernarus values - works on Livonia, Namalsk, custom maps

  • ⚡

    Performance Optimization

    Object pooling for HUD markers, lazy widget creation, reduced memory footprint

2
🎯 User Experience Q2 2025
  • 🏷️

    Marker Categories

    Tag markers as Base, Loot, Danger, Meeting Point, etc. Filter by category on map and in list

  • 🔍

    Search & Filter

    Text search to find markers by name, filter panel by type, sort by distance from player

  • 📝

    Marker Notes

    Add detailed descriptions to markers beyond just the name - loot lists, warnings, coordinates

  • 🔔

    Proximity Alerts

    Optional audio/visual notification when approaching a waypoint marker

3
🚀 New Features Q3 2025
  • 📍

    Route Drawing

    Connect markers with lines to create travel routes. Polyline paths with distance calculation

  • ⏱️

    Temporary Markers

    Markers that auto-expire after set time. Perfect for "meet here in 10 minutes" scenarios

  • 📤

    Import/Export

    Export marker sets to JSON files, share with friends, import community POI packs

  • 🔭

    Marker Clustering

    When zoomed out, nearby markers group into clusters with count badges

4
👥 Multiplayer & Social Q4 2025
  • 👨‍👩‍👧‍👦

    Party System

    Create groups, invite players, share party markers in real-time. See teammate positions on map

  • 📡

    Marker Sharing

    Share individual markers with other players - send a location ping to your group

  • 🎨

    Custom Icons

    Upload and use custom .paa marker icons. Server-side icon packs

  • 🗺️

    Map Overlays

    Add image overlays to map - base blueprints, territory boundaries, trade zones

5
🔌 Integration & API 2026+
  • 🧩

    Mod API

    Public API for other mods to create/manage markers. Quest markers, trader locations, event zones

  • 🌐

    Localization

    Multi-language support via string tables. Community translations welcome

  • 🔄

    Hot Reload Config

    Server admins can update settings without restart. RCON integration

  • 📊

    Analytics Dashboard

    Optional server-side tracking of popular locations, heatmaps for admins
