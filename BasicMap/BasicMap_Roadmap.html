🗺️ BasicMap - Code Review & Roadmap

Generated: December 17, 2025 | DayZ Mod Development

✅Strengths

  • Well-organized architecture - Clean separation between controller (BasicMapController), data models (BasicMapMarker, BasicMapCircleMarker), and UI (BasicMapMenu, BasicMapHUDMarker)
  • Good singleton pattern - BasicMap() provides consistent global access
  • Flexible marker system - Groups, factories, and inheritance allow extensibility
  • Server/client sync - RPC-based synchronization for server markers is solid
  • Feature-rich configuration - BasicMapConfig offers server admins good control (compass requirements, GPS, map items)
  • Visibility modes - Nice implementation of cycling through SHOW_ALL / SERVER_ONLY / LOCAL_ONLY / HIDE_ALL
  • Navigation HUD - Compass and minimap tied to inventory items is immersive

🗺️Roadmap Suggestions

🔴 Priority 1: Bug Fixes & Stability
  1. Complete BasicMapHasPen() - Currently empty, likely breaks pen-required marking
  2. Map bounds detection - Use GetGame().GetWorld().GetBoundBox() instead of hardcoded 15360
  3. Null safety audit - Add defensive checks in HUD update loops
🟠 Priority 2: Quality of Life
  1. Marker categories/tags - Allow filtering markers by type (trader, base, danger, etc.)
  2. Search/filter in marker list - Text search to find markers quickly
  3. Marker distance sorting - Option to sort marker list by distance from player
  4. Marker sharing between players - Share personal markers via RPC to party/friends
🟡 Priority 3: New Features
  1. Route/path drawing - Connect markers with lines to create routes
  2. Dynamic/temporal markers - Markers that expire after X minutes (temporary waypoints)
  3. Marker import/export - JSON export for sharing marker sets externally
  4. Marker LOD system - Cluster nearby markers when zoomed out on map
  5. Audio cues - Proximity notification sounds when approaching waypoints
🟢 Priority 4: Advanced Features
  1. Party/group system integration - If you add parties, sync markers per-group
  2. Custom marker icons - Allow players to use custom .paa files
  3. Marker notes/descriptions - Extended text per marker (not just name)
  4. Map overlay images - Support for custom map overlays (base blueprints, zone boundaries)
  5. Mission/quest marker API - Let other mods create markers programmatically
🔵 Priority 5: Performance & Polish
  1. Lazy loading for markers - Don't create all HUD widgets at once
  2. Object pooling - Reuse BasicMapHUDMarker instances instead of recreating
  3. Config hot-reload - Allow server admins to reload settings without restart
  4. Localization support - String table for multi-language UI
